# 长期记忆角色组合实跑报告：顾砚舟与岩行者

> 这是一份独立的角色案例报告，不是 `报告.md` 的待解决问题。`报告.md` 只保留未解决/待裁定事项，已经结案的旧战报不再混在那里。
>
> 本案例使用真实 `GameEngine` 的开局、事件、回始、队友指令和 `use_daowen` 管线。每次行动均由 `GameEngine.execute_action()` 校验并落地；数值取自引擎返回值。为了把组合链条清楚地展示出来，战斗构筑中的道纹是在受控测试夹具中注入当前角色的，不把这段短报告冒充成自然七场通关记录。

## 1. 角色不是换一个名字，而是一条选择逻辑

**顾砚舟｜seed=4｜名字检索确认未与仓库既有角色重名**

长期记忆开局自述：

- 身世：曾是龙心谷边缘村落的守夜人，亲眼看过同伴被龙火带走；
- 遗憾：明明看见危险，却因为犹豫错过了出手时机；
- 价值观：活下来比证明自己勇敢更重要；
- 恐惧：活着，却逐渐认不出自己；
- 目标：让至少一个同行者安全离开这一轮。

这个目标决定了他不会把队友当成一次性护盾。顾砚舟的破局方式是：自己承担一部分血债，把代价拆给愿意同行的人，再让队友替他挡住真正会杀人的那两下。

## 2. 构筑与羁绊来源

### 开局构筑

- 开局遗物候选：`回锋刀 / 血契 / 买路财`；选择 **血契**。
- 初始道纹候选：`增殖 / 贯穿 / 庇护`；选择 **庇护**。
- 副本：龙心谷。
- 受控组合道纹：**逆鳞、加害、裂变、血债**。
- 实战敌人：引擎真实抽取的 **石背熊**（血限252，2×7），没有凭空捏造敌方规则。

### 队友不是装饰

顾砚舟在真实龙心谷事件【断桥余烬】中选择“接过伤者”：

```text
引擎返回：流血10；岩行者作为朋友加入
岩行者：2×4 / 54，持有道纹【背负1】
顾砚舟生命：54 → 44
```

这不是报告作者手写的队友名。`岩行者`由事件正文和事件结算代码实际创建；他的“背负”也不是叙事标签，而是后续 `command_ally` 能调用的真实道纹。

## 3. 两回合组合破局

### 第一回合：血契供能，逆鳞立债，加害改写伤害

1. **遗物【血契 X=4】（回始）**
   - 顾砚舟选择让岩行者分担代价；
   - 引擎结算：总流血16，由两人共同承担，获得4点法力。
2. **队友指令【护卫2】**
   - `command_ally(friend:0, "护卫 2")` 成功；
   - 岩行者接下两次本应落到顾砚舟身上的攻击，且不消耗自己的出手。
3. **道纹【逆鳞 X=4】**
   - 顾砚舟与岩行者再次按血契分担流血4；
   - 石背熊获得4层逆鳞，之后受到伤害时可把这些层数转成反击增幅。
4. **道纹【加害 X=1】**
   - 消耗3法力；
   - 石背熊获得永久【加害1】，每次受到伤害都会被放大。
5. **怪物阶段**
   - 石背熊发动两次7点攻击；
   - 顾砚舟没有继续闪避，岩行者的背负把这两次攻击接走；
   - 顾砚舟仍保持34点生命，岩行者承受了保护代价，但羁绊确实改变了伤害归属。

这一回合的看点不在“按一下防御”，而在于：血契先把资源代价变成两人的共同秘密，背负再把敌人的攻击变成队友主动承担的承诺；顾砚舟可以把自己的血量投入后续组合，而不会立即被敌方两连击打断。

### 第二回合：裂变铺轨，血债收束

1. **遗物【血契 X=6】（回始）**
   - 再次由顾砚舟和岩行者共同承担24点流血，获得6点法力；
   - 这是一次危险的选择：顾砚舟已经不是满血，岩行者也只剩下可承受的血量，但目标是让至少一个同行者活着离场。
2. **道纹【裂变 X=2】**
   - 消耗6法力；
   - 石背熊获得永久【裂变2】，之后的伤害被拆成两次结算。
3. **道纹【血债 X=3】**
   - 顾砚舟和岩行者再次分担流血代价：顾砚舟支付2，岩行者支付1；
   - 原始伤害为3，叠加【加害1】、【逆鳞4】和【裂变2】后，引擎返回实际伤害 **6**，石背熊生命 **252 → 246**；
   - 本次没有把“实际伤害6”写成角色臆测，`use_daowen` 的 `execution.effects` 明确返回了 `raw_damage=3`、`actual_damage=6`。

### 二回合落点

```text
顾砚舟：生命 44 → 20，法力归零
岩行者：生命 54 → 17，仍存活
石背熊：生命 252 → 246
石背熊身上：逆鳞4 / 加害1 / 裂变2
```

这不是“顾砚舟一个人放大招然后队友站旁边看”。队友的事件代价、血契分担、背负护卫和后续多段道纹都真正改变了行动顺序与伤害归属。顾砚舟也没有无伤获胜：他把自己逼到20血，把岩行者逼到17血，换来了能继续滚动的组合状态。

## 4. 这才是适合长期记忆的角色经历

顾砚舟这一轮记住的不是“我曾经招架过一次”，而是：

> “我终于知道，欠下的血债不能只记在一个人身上；但如果有人愿意和我一起背，代价就能换来下一次出手。”

这条经历可以继续改变他的性格：他可能更信任岩行者，也可能在下一场拒绝再次把队友拖入血契。两种选择都必须由下一次真实行动产生，而不是由报告替他宣布。
