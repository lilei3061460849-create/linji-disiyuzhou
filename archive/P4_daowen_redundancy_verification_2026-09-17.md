## 一、结论速览

| 报告论断 | 核实结果 |
| --- | --- |
| 5.2-1「自愈 vs 滋养：回复公式逐字相同」 | **部分成立**：数值口径同为「血限的 10X%」，但实现不同（自愈交付 `heal_percent` 给[回始]触发器、滋养当场 `ceil(血限×10X/100)`）；且**代价轴不同**（自愈＝异变5X 的代价类、滋养＝2X法力的消耗类）、**时机不同**（每回合订阅 vs 一次性）、**目标不同**（自身 vs 可选目标）。不是纯重复。 |
| 5.2-2「加速/超频/兴奋/急速 四条挤在一个概念上」 | **概念成立、非重复**：加速＝获得速度翻倍（5X法力，持续X）；超频＝速度+X（2X法力，可选目标含友方）；兴奋＝每次出手后+1（2X法力，持续X）；急速＝每闪避两次+1（5X法力，持续X）。四条的触发器/数值形状/代价档各不相同。 |
| 5.2-3「加害 vs 龙鳞：+X 与 -X 纯对称」 | **完全成立（唯一确证的纯重复）**：同为 2X 法力消耗类、同为「每次受到伤害」触发、同为持续∞、数值仅符号相反（+X / -X 且最低0）。 |
| 5.1「冥气 的同效果独立道纹＝减速」 | **不成立**：冥气＝2X法力、每失去一次速度→**[速限]-2**（削上限、持续X）；减速＝异变5X 代价、**当前速度减半**（削现值、持续X）。削的字段与代价轴都不同。 |
| 5.1「伤痕 的同效果独立道纹＝瓦解」 | **不成立（形状不同）**：伤痕＝2X法力、每次掉血后血限-X（逐次定额、永久）；瓦解＝3X法力、血限-10X%（一次性百分比）。 |
| 5.1「洞察 的同效果独立道纹＝透支/搏命」 | **弱成立**：三者都产法力，但洞察是「每次闪避后下回合法力+10」（触发器型、代价疲惫X），透支＝流血4X→+X法力、搏命＝疲惫X→+X法力（一次性）。**更近的一对是透支 vs 搏命**（同为一次性「获得X点法力」，只差代价轴：流血4X / 疲惫X），报告未列此对。 |
| 5.1「爆裂/尸爆 的同效果独立道纹＝杀伐」 | 未逐字核（属伤害产出类，触发条件差异明显：受伤后反伤 / [命零]时 AoE / 主动出手）。 |
| 5.3 元机制类（波及/缄默/裂变/定型/退化/逼债） | 分类成立。**其中「缄默」当前无消费方**（状态写在 `wave_status_targets`，引擎无处读取），见待裁定项。 |
