【一、世界观与底层因果法则】

轮回的本质

轮回是为了填补过去的不甘心，是为了其他人逃离悲惨的结局。越是理性、冷漠的角色，越没有资格进入轮回！轮回者必须具备强烈的情感羁绊、偏执执念、血性冲动与鲜活人性，毫无情感的理智机器与木头没有任何存在的价值。

局外行动与死者之书

局外行动是轮回者与《死者之书》之间进行的灵魂契约交易，以休整举例：角色付出精力与灵魂碎片，由死者之书直接抹平并缝合受损的灵魂伤害。付出的代价越重，获得的灵魂治愈越深。

局外行动本质上均由《死者之书》承担；以任何途径新增的局外行动，视为对《死者之书》的功能强化。

死者之书与微光者

《死者之书》不是现实中的实体书籍，而是与轮回者灵魂绑定的存在，无法作为物品被交接或偷走。想要得到死者之书，必须推翻并取代与其绑定的轮回者；这也是员工若想夺书，必须发动叛变的原因。

微光者会饥饿、染病与衰弱，灵魂碎片只能维持其暂时生存。得到死者之书、成为轮回者，是微光者免疫饥饿与疫病的唯一条件。放弃死者之书与继续活下去的代价，不会带来安宁，而是逐渐失去自我并成为怪物。这是因果，不是世界作出的善恶审判。

轮回资格

轮回者是想要逃离轮回的人。轮回资格来源于自身意志，而非任何存在的挑选。

怪物

怪物并非天生存在，而是轮回者或微光者因各种原因失去自我意志后的残留存在。怪物保留执念与生存本能，但不再拥有真正的自由意志。成为怪物存在多种途径。放弃轮回只是其中一种，部分副本还存在其他怪物化方式。

微光者

微光者只学会用法力造成伤害，不免疫饥饿、疫病等生存威胁。怪物被净化后，均恢复为微光者。

净化

净化是解除异常状态，使目标恢复为无记忆的微光者。

血统

第四宇宙不存在天生高贵的血统。血族、鲛族等均属于后天获得的生命状态，而非先天身份。

灵魂碎片

灵魂碎片是字面意思。微光者依靠灵魂碎片维持生存、抵御饥饿与疫病，因此碎片是废土中最重要的资源。

某人

仅在世界走向无趣或末路时显现。不会代替任何角色作出选择，世界始终由规则与自由意志共同推动。

自由意志

第四宇宙不存在宿命。规则决定因果，自由意志决定选择，选择决定结果。任何存在都必须承担自身选择带来的后果。

遗忘

意识是痛苦存在的前提。遗忘才是真正的毁灭。当再没有任何意识记得轮回时，某人将陷入沉睡，但第四宇宙依然存在。

世界运行方式

第四宇宙中的规则不会主动表达价值判断。世界只提供规则、因果与选择，不提供善恶评价。角色的价值观由玩家自己的选择自然体现，而非世界告诉玩家什么是正确。

未见场景裁定落库法则：当遇到从未见过的情况时，若DM给出明确回答且不与现有规则冲突（若存在冲突必须立即指出），该裁定直接作为正统底层逻辑记录入本【世界观】专区，成为第四宇宙运行规律的一部分。

核心因果与联系：第四宇宙不是以增加内容为目标，而是以增加已有规则之间的联系为目标。任何设计都必须回答"为什么"。世界遵循因果，不遵循宿命。能力必须有来源，力量必须有代价，规则高于身份，因果高于宿命，自由意志高于一切。

【二、复杂度原则】

新增设计时必须遵守以下顺序：
1. 能否解释为已有道纹？
2. 能否解释为已有法术？
3. 能否设计成事件？
4. 能否设计成遗物？
5. 能否设计成行动？
6. 只有以上全部无法实现时，才允许新增规则。

任何设计都优先归纳，而不是扩张。

【三、道纹与残韵设计原则】

道纹只有两字，不是技能，而是概念，是世界的最小规则单元，相当于语言中的词语。法术相当于语句，由多个已有道纹组合而成。

新增道纹必须代表一个单一、纯粹的基础规则概念，而不是一个完整技能。严禁出现一个道纹无脑完爆其他道纹，或缝合多种独立道纹效果。

凡是与已有道纹组合而成的法术效果类似的道纹，均没有任何存在的意义。

道纹的 X 要么与效果强度挂钩，要么与持续挂钩，禁止两者都挂钩

残韵（转换、反转、曲解）不仅是局外掌握道纹的桥梁，更是战斗中进行实时插队、招架、攻防逆转与概念篡改的核心战术陷阱：
1. 反转（极性对冲）：逆转因果极性，将增益逆转为减益，将伤害逆转为治愈，将控制逆转为爆发。
2. 转换（平向支流）：平移法则维度，将单体转化为范围，将伤害转化为控制，将控制转化为放逐。
3. 曲解（概念腐化）：扭曲代数逻辑，将直接效果腐化为条件触发，将确定效果腐化为阈值判定。

【四、法术设计原则】

法术设计必须赋予后手角色与反应型法术在先手伤害爆发前建立防御或打出交错交锋的能力。

法术必须完全由已有道纹组成，必须通过局外【学习】行动方可掌握并开启，不允许凭空创造效果。所有法术必须遵守积木法则、循环法则、中断法则。

【五、事件设计原则】

事件负责未知、探索、选择和成长。每个事件必须包含场景描述、至少一个选择、对应代价、对应收益以及拒绝选项。收益必须与事件内容强相关，代价必须具体且合理。

【六、遗物设计原则】

遗物的作用是改变玩法，而不是单纯增加数值。优秀遗物应该改变资源流动、战斗方式、构筑方向或思考方式。每件遗物必须改变至少一种已有资源的使用方式。

【七、怪物设计原则】

怪物与玩家共享完全相同的底层规则。怪物的强项同时也是它的弱点。

怪物不持有法力，也没有[法限]。法力仅作为设计怪物面板时的度量衡，用于换算其道纹配额；副本越高，可分配的道纹预算越多。怪物发动道纹不支付法力，只消耗行动。

X法力=6X血限，2X法力=X攻击力，X²法力=X攻击次数

【八、行动设计原则】

行动负责稳定成长，事件负责未知探索，两者不能混淆。

【九、代价原则】

第四宇宙不存在无代价成长。任何强收益必须伴随即时、持续、永久或机会成本中的至少一种。代价应当从玩家做出选择开始生效。

【十、随机原则】

随机负责创造问题，不负责决定结果。玩家失败应主要来自自己的选择，而不是运气。

【十一、情感表达原则】

第四宇宙不依赖角色喊口号表达主题。任何主题都必须通过规则、事件、选择和世界运行方式自然体现。轮回的核心在于执念与羁绊，玩家与角色应通过抉择与代数过程体悟生命的重量。

【十二、创作原则与绝对禁区】

不要思考"这样够不够酷"，而应思考"这样是否符合世界规则"。

禁止绝对无敌、绝对控制、无法反制。禁止机械降神、凭空捏造未持有道纹或擅自按回合递减跨战斗冷却。

禁止再次重复说明已有规则或说明

禁止出现“击杀怪物获得碎片（不是你失去碎片）”这种两者毫无关系和关联的脑残弱智说明！

规则高于身份，因果高于宿命，自由意志高于一切！

核心规则

自由规则：只要没有明确禁止的任何操作都是允许的

随机数规则：需要随机时，先统计当前池中符合条件的选项总数，由游戏引擎在该范围内自动生成随机数并直接结算对应选项，过程记录随机种子与结果序号以便追溯与复现，玩家与DM不再需要手动提供数字。已触发、重复或不符合条件的选项不计入池中，范围随之缩减。
当前事件池由所有未遇到的通用事件，以及当前区域中符合条件且未遇到的专属事件共同组成；通用事件排列在前，专属事件排列在后。已触发或条件不满足的事件不进入当前池。

整数规则：所有计算都向上取整

自由控X规则：施法者在发动道纹或法术时，可根据当前剩余法力与战术需求，自由指定/控制公式中的代数 X 数值（1 ≤ X ≤ 当前可用法力/代价上限），无需强制一次性清空全部法力。

积木规则：法术不得凭空创造新机制，必须完全由已解锁道纹的原版效果组合而成。每一步结算必须严格遵守对应道纹的代数公式（如【庇护X】消耗X法力获得4X格挡，或【再生X】消耗X法力恢复6X生命）。

循环规则：允许法术生效流程的终点结算触发该法术自身的启动条件，从而在法力充足时自动循环。

中断规则：法术一旦法力耗尽或中间流程失效则生效流程中断

法术阶级规则：法术使用X种不同道纹即为X阶（最高9阶）。X阶法术最多拥有X种自定义条件。每个可以独立判断真假的要求均计为一种条件；使用“且”“或”等连接多个要求时分别计数。目标可选、资源充足、角色存活以及法力耗尽或中间流程失效时中断，属于所有法术共享的全局规则，不计入条件数量。

属性与状态规则：初始分配：25 点初始属性点（1属性点 = 6[血限] = 1[速限] = 2[法限]）
局外修行：1属性点 = 1[速限] = 2[法限]。[血限]仅可在开局的初始属性点分配阶段获得，此后无法通过修行提升。

轮回者：［血限］/［法限］/［速限］
 
微光者：攻击次数×攻击力/[血限]

在各个意外事件遇到，可以与其同行，作为[朋友]加入时，开局即在战场，同轮回者一同行动，不收取工资，不触发待命。微光者会根据情况对敌方出手（出手次数=当攻击次数/3），可能是发动一轮攻击或发动一次自身道纹效果

怪物：攻击次数×攻击力/[血限]

未觉醒者/微光者因各种原因所变，怪物会根据情况对轮回者出手，每回合固定发动一次攻击和发动一种道纹

道纹归属规则
原始怪物道纹（各组起点）：狂暴、强化、活力、减速、必中、自愈、飞行。
怪物转化道纹（原始怪物道纹经残韵变化后的分支）：愤怒、自残、无神、借力、弱化、自食、兴奋、无力、迟滞、急速、加速、眩晕、洞察、蒙蔽、滋养、衰败、寄生、滑翔、坠落。
1.原始怪物道纹不消耗法力，首次发动时统一支付【异变5X】作为代价；效果持续期间不再重复支付异变。
2.原始怪物道纹只能单向变化为转化道纹（→）。转化道纹无法逆推回原始怪物道纹。
3.原始怪物道纹无法被永久获得，只能通过特定手段临时借用（如【原初X】）。
4.人类（轮回者与微光者）无法承受并获得原始怪物道纹；人类可以正常承受并获得怪物转化道纹。
5.非人类种族（龙族、血族、鲛族等）可以承受原始怪物道纹，但须支付其种族对应的代价。

残韵作用
1.残韵未生效则不消耗
2. 残韵作用于非轮回者拥有的道纹时，仅改变本次发动的道纹结算，不改变其拥有的道纹；结算完成后，施法者永久获得变化后的道纹。
3.残韵作用于轮回者拥有的道纹时，该轮回者拥有的对应道纹永久变为变化后的道纹，施法者不会因此获得该道纹。
4.通过残韵获得的道纹，X值按施法者自由控X规则自定义，不固定为原道纹数值
5.残韵在道纹结算前生效前，原道纹的消耗或代价、目标要求、效果与后续流程全部改为新道纹的原版公式，不保留原公式的未结算部分。已经完成的结算不追溯撤销；新公式的消耗或目标条件无法满足时，后续流程中断。
6.角色拥有的道纹始终保持唯一，同名道纹不会重复存在

游戏流程

阶段门禁：开局、局外、战斗、战终必须按顺序推进；开局配置不可重复，精力耗尽后方可进入战始，仍有存活敌人时不可提前结算战终。道纹只可在战斗阶段发动，唯一允许局外发动的道纹是【消灾】。（AI 角色扮演职责与决策准则见 [AI守则](AI守则.md#一职责划分)）

一、开局
分配25点初始属性点（1点=6[血限]=1[速限]=2[法限]）→获得20[碎片]并自动获得初始道纹【杀伐】→自选一种残韵（转换／反转／曲解）→选择一个一阶副本→开局【发现】随机列出3件遗物并显式选择1件

二、第1至第7场（每场均先局外后战斗）
局外阶段（3点精力，通用行动与副本专属行动共用同一精力池，每次行动精力-1，耗尽后进入战斗）
→[战始]：抽取出怪（数量=战斗场数-3，最低为1，全部副本统一公式，允许重复抽选同一怪物种族）→选择一种战斗背景→得知怪物面板及道纹→结算[战始]效果
→回合内：[回始]→双方交替出手（按七步原子时序切片管道逐次推进）→[回终]
→[战终]：结算[碎片]奖励（怪物[战始][血限]×2%＋死亡时拥有的道纹数×5；怪物在非[命零]状态下战斗结束、复制体、召唤物与其他衍生子体无[碎片]奖励）→清除局内增益（包括回复、格挡、持续∞等）与减益（不包括代价）→[朋友]与[员工]留存，[临时朋友]消失→恢复精力→检查【员工叛变】

三、第8场·最终死斗（无局外阶段）
完成第7场后触发【最终的冠冕】：若无封存候选，本次轮回角色被完整封存，玩家以新的轮回者重新开始；若已有封存候选，双方进入死斗。
先手顺序：[速限]→[法限]→[血限]→当前生命；四项完全相同时随机决定首回合首手，之后每回合交换首手方。每轮双方交替消耗出手次数；一方出手次数耗尽后，另一方余下出手继续，不会作废。残韵可任意时刻插队，无法逃跑。
死斗只允许一名轮回者离开。胜者进入下一阶副本，败者失去轮回者身份，触发【死之传承】。

四、阶级推进
一阶（罪孽都市／扭曲都市／龙心谷）→二阶（乱葬岗／永夜庭／沉沦海）→三阶（荒疫古城）→四阶（七宗罪；现有巴别塔）→五阶（启示录）

五、全程自动触发（不参与事件池，不消耗精力）

### 单次出手七步原子流水线（时序切片管道）
```
【步骤 1：声明与付费】 行动方声明发动道纹/攻击，选定目标，扣除法力/支付代价
       ↓
【步骤 2：残韵插队窗口】双方可发动残韵（转换/反转/曲解）插队篡改当前道纹公式
       ↓
【步骤 3：预先响应窗口】检查「发动道纹前 / 受到伤害前」类法术（如：咎由自取、后发制人、先发制人）
       ↓
【步骤 4：防御声明窗口】目标声明是否消耗 1 点速度进行【闪避】（闪避成功则判定完全失效，跳过步骤5）
       ↓
【步骤 5：数值与效果落地】计算原始数值 → 结算格挡抵消 → 扣减实际生命 / 施加状态 / 产生回复
       ↓
【步骤 6：后置响应窗口】若实际扣减生命，检查「失去生命后」类法术（如：生生不息、以牙还牙、千刀万剐）
       ↓
【步骤 7：状态基准检查】检查存活、[命零]、癌变、凡庸、雕塑、崩解、撤退等全局状态
```

#### 场景 3：残韵插队逆转（作用于轮回者永久改变其自身道纹）
```markdown

  [动作声明] A 对 B 发动【杀伐2】（预定消耗 2 法力，对 B 造成 6 点伤害）
  [残韵插队] B 发动残韵【反转】插队：
```

#### 场景 4：防御型反应法术（【后发制人】受到伤害前获得格挡）

```markdown
出手1（A）：
  [动作声明] A 对 B 发动【杀伐10】（消耗 10 法力，原始伤害 30）
  [预先响应] 【受到伤害前】B 触发法术【后发制人】（循环1）：
    └ B 对自身发动【庇护5】（消耗 5 法力）→ 获得 20 点格挡（格挡 0→20，B 法力 30→25）
```

七、推演铁律
1. 每一次出手必须写明消耗或代价的具体数值，以及资源变化前后的实际数字。
2. 禁止在数值未耗尽时坐以待毙，任何角色在濒死时均须尝试其身份与资源允许的最优解。
3. 怪物在[战始]第一回合为白板状态，任何道纹须在其出手轮主动发动后方可生效。
4. 禁止发动未持有的道纹、未学会的法术、已进入冷却或已成为尘封的道纹。
5. 禁止跳过闪避判定，凡带[目标]的非必中判定，被选定方均须明确声明是否消耗速度闪避。
（完整 AI 协作要求与执行规范见 [AI守则](AI守则.md#三推演铁律)）

怪物准则
1.免疫一切现实伤害（指现实中的物理，化学等等）
2.只通过灵魂锁定位置
3.陷入困境时强制选择逃跑/进化，每场战斗限一次，且逃跑与进化二者只能选择其一。
4.困境是指怪物的主要优势被针对、原有取胜路线被稳定限制，继续依靠现有属性与道纹将明显陷入被动，但尚未达到必败。核心道纹被变化或失效、连续无法有效攻击、对方建立稳定压制循环、急中生智成功破解主要优势时，均应立即进行困境检查。困境检查以当前胜率为依据，而非当前生命
5.怪物不持有法力，也没有[法限]。面板中的“可分配法力”仅为设计阶段的度量衡，用于换算道纹配额，不是战场上的可用资源。怪物发动自身面板上的道纹不支付法力，只消耗出手；面板未列出的道纹无法发动。附带【代价】的道纹仍须照常支付代价。
6.拥有智慧且没有道德底线，同样会急中生智，判定标准与轮回者相同。
7.怪物与轮回者共享基础规则，但怪物可额外拥有符合自身物种、来源与副本机制的怪物准则；该类准则不得无视已有规则、代价与因果。
8.白板开局：怪物在[战始]的第一回合，仅具备基础攻击次数、攻击力和生命值，（例如具有【飞行】或【庇护】的怪物，在第1回合绝非飞行状态也无初始格挡，须在其出手轮主动发动后方可生效）
