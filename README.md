## 五分钟上手

1. **开局**：分配 25 点初始属性点 → 领 20[碎片] → 【发现】3 件遗物选 1 → 从杀伐闭环【发现】3 种道纹选 1 → 自选一种残韵 → 选一个一阶副本。
2. **每场**：先局外（3 点精力，行动清单见《局外系统》），精力耗尽进战斗；战斗按七步原子时序逐次出手，敌方全灭后结算[战终]。
3. **一轮回**：第 1～7 场常规战斗，第 8 场最终死斗；胜者晋级下一阶级副本，[命零]即触发【死之传承】。

查具体条文：方括号名词见[基础定义](AI_EXPERIENCE.md#基础定义)，局外行动价目见[局外系统](AI_EXPERIENCE.md#局外系统)，
道纹效果见[全道纹索引](全道纹索引.md)，遗物见[物品索引](物品索引.md)。

## 游戏流程

阶段门禁：开局、局外、战斗、战终必须按顺序推进；开局配置不可重复，精力耗尽后方可进入战始，仍有存活敌人时不可提前结算战终。道纹只可在战斗阶段发动，唯一允许局外发动的道纹是【消灾】。（AI 角色扮演职责与决策准则见 [AI知识库](AI_EXPERIENCE.md#职责划分)）

一、开局
分配25点初始属性点（1点=6[血限]，2点=1[速限]=1[法限]）→获得20[碎片]并开局【发现】随机列出3件遗物，显式选择1件→从杀伐闭环【发现】3种未持有候选，显式选择1种作为初始道纹；杀伐不是默认起手→自选一种残韵（转换／反转／曲解）→选择一个一阶副本

二、第1至第7场（每场均先局外后战斗）
局外阶段（3点精力，通用行动与副本专属行动共用同一精力池，每次行动精力-1，耗尽后进入战斗）
→[战始]：抽取出怪（数量=战斗场数-3，最低为1，全部副本统一公式，允许重复抽选同一怪物种族；波次进场：R1只出第1只，R4/R7/R10…回始各增援1只直到上限，增援怪进场当回合白板不出道纹）→选择一种战斗背景→得知怪物面板及道纹→结算[战始]效果
→回合内：[回始]→双方交替出手（按七步原子时序切片管道逐次推进）→[回终]
→[战终]：结算[碎片]奖励（怪物[战始][血限]×2%＋死亡时拥有的道纹数×5；怪物在非[命零]状态下战斗结束、复制体、召唤物与其他衍生子体无[碎片]奖励）→清除局内增益（包括回复、格挡、持续∞等）与减益（不包括代价）→[朋友]与[员工]留存，[临时朋友]消失→恢复精力→检查【员工叛变】

战斗结束与胜利判定：
1.战斗胜利＝敌方全部角色【命零】或【离场】。一切使角色脱离本场战斗的特殊事件——雕塑、癌变、还债、救赎、封印、事件裁定的逃跑，以及未来新增的任何特殊事件——一律视为【离场】。离场不视为击杀、不产生[碎片]（[碎片]只来自[命零]，按上述公式）。敌方全部命零或离场后方可结算[战终]。
2.战斗失败＝轮回者[命零]，无论死因（伤害、凡庸、癌变、崩解、代价致死等），立即触发【死之传承】。
3.双方在同一结算拍同时满足条件时，按对应事件的优先规则裁定（如凡庸：非轮回者优先，先炸裂者使战斗胜负已定则中断剩余结算）。

三、第8场·最终死斗（无局外阶段）
完成第7场后触发【最终的冠冕】：若本阶级无封存候选，本次轮回角色被完整封存，玩家以新的轮回者重新开始；若本阶级已有封存候选，挑战者与队首候选进入死斗。
先手顺序：[速限]→[法限]→[血限]→当前生命；四项完全相同时随机决定首回合首手，之后每回合交换首手方。每轮双方交替消耗出手次数；一方出手次数耗尽后，另一方余下出手继续，不会作废。残韵可任意时刻插队，无法逃跑。
死斗只允许一名轮回者离开。胜者进入下一阶级副本，败者失去轮回者身份，触发【死之传承】。

死斗规则及程序：
1.死斗按阶级进行：挑战者只能与自身副本阶级的封存候选死斗；每个阶级的封存候选按先来后到排队，挑战者依次与队首死斗。
2.通过死斗的角色进入进阶封存：一阶死斗胜者进入二阶封存槽，二阶死斗胜者进入三阶封存槽，以此类推。进阶封存后不得再与原阶级角色重复死斗。
3.被封存的角色在该阶级槽中等待下一名同阶级挑战者；同阶级槽可有多名候选依次排队。
4.死斗败者失去轮回者身份，触发【死之传承】。

四、阶级推进
一阶（罪孽都市／扭曲都市／龙心谷）→二阶（乱葬岗／永夜庭／沉沦海）→三阶（荒疫古城）→四阶（七宗罪；现有巴别塔）→五阶（启示录）

五、全程自动触发（不参与事件池，不消耗精力）
死之传承、凡庸、癌变、还债、雕塑、员工叛变、许愿、逃跑与追击、进化、崩解、撤退、最终的冠冕、初拥之夜、救赎

六、战斗推演格式

每场战斗必须按以下格式逐回合书写，禁止概括、跳过或合并结算。

凡【发现】必须先写本次列出的全部候选，再写显式选择；禁止只写选择结果。开局发现遗物与开局发现初始道纹同此格式。

### 战斗整体结构
```
[开局]
属性：血/速/法点数＝[血限]/[法限]/[速限]，出手次数｜碎片
遗物发现：候选〔甲、乙、丙〕→选择【所选】
初始道纹发现：候选〔甲、乙、丙〕→选择【所选】
残韵：转换／反转／曲解
副本：名称

[战始]
出怪：范围与随机数结果→本场敌人清单
战斗背景：（名称与影响）
敌方面板：名称（攻击次数×攻击力/[血限]，道纹）
我方面板：轮回者（[血限]/[法限]/[速限]，出手次数）｜[朋友]与[员工]（攻击次数×攻击力/[血限]，道纹）
[战始]效果结算：（遗物、法器、法术开启，逐条列出）

第N回合
[回始]：资源面板（双方当前生命/[血限]、当前法力/[法限]、当前速度/[速限]、格挡、持续X剩余回合）→[回始]类效果逐条结算
出手1（行动者）：
  [动作声明] 对 [目标] 发动 [道纹/攻击]（消耗或代价）
  [残韵插队] （若有）[插队者] 发动残韵【类型】插队 → 改变道纹与所有权
  [预先响应] （若有）【受到伤害前】[响应者] 触发法术【法术名】→ 步骤结算
  [目标反应] [目标] 闪避（速度-1） / 选择不闪避
  [数值落地] 原始数值 → 格挡吸收 → 实际伤害/回复/状态变化（数值前→后）
  [后置响应] （若有）【失去生命后】[响应者] 触发法术【法术名】→ 逐步或循环结算
出手2（行动者）：同上
（按出手次数依次列出；怪物每回合的攻击出手与道纹出手分别按引擎列出的合法选项结算）
[回终]：[回终]类效果结算→持续X剩余回合-1→本回合资源面板（格挡不在此处清空）

[战终]
死亡结算→[碎片]奖励计算→增益与减益清除→代价保留项→[朋友][员工]留存与[临时朋友]消失→精力恢复→【员工叛变】检查
```

七、推演铁律

完整 11 条见 [AI知识库·推演铁律](AI_EXPERIENCE.md#推演铁律)。最常踩的五条：
1. 每一次出手必须写明消耗或代价的具体数值，以及资源变化前后的实际数字。
2. 禁止在数值未耗尽时坐以待毙，任何角色在濒死时均须尝试其身份与资源允许的最优解。
3. 怪物在[战始]第一回合为白板状态，任何道纹须在其出手轮主动发动后方可生效。
4. 禁止发动未持有的道纹、未学会的法术、已进入冷却或已成为尘封的道纹。
5. 禁止跳过闪避判定，凡带[目标]的非必中判定，被选定方均须明确声明是否消耗速度闪避。
